# v1.1.0 ONLINE 修正版

## 關鍵修正
- 預設 `AUTO`，不再預設 Sample。
- `AUTO` / `ONLINE` 永遠使用真實來源，不會自動切回 Sample。
- 無 API Key 時仍透過 Google News RSS 收集最近 72 小時真實新聞。
- 設定 `GNEWS_API_KEY` / `NEWSAPI_API_KEY` 後會合併更多真實來源。
- 正式來源全失敗：`SOURCE_FAILED`；來源可連線但無資料：`DATA_UNAVAILABLE`。
- Truth Social 未設定官方／授權 Token 時，清楚標示 `AUTHORIZED_SOURCE_NOT_CONFIGURED`，不以範例貼文替代。
- Sample 僅能由 UI 手動選擇或測試腳本使用。

## GitHub Secrets
- `GNEWS_API_KEY`（選用）
- `NEWSAPI_API_KEY`（選用）
- `TRUTH_API_TOKEN`（取得官方／授權服務後才使用）
